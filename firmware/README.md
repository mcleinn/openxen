# firmware — libhmk-derived module firmware

- `keyboards/openxen-m56/keyboard.json` — generated by `generators/gen_keyboard_json.py` from `layout/module.json` (mux matrix, pins, layout).
- The libhmk fork itself is added in Phase 7 (as a submodule or vendored copy, GPL-3.0). Until then the unmodified reference build runs in `reference/repos/libhmk` (see `docs/reference-build.md`).

Planned additions on top of libhmk: vendor-HID analog stream, LED driver (variant A: SK6812MINI-E chain over SPI+DMA, variant B: matrix driver), LED/brightness commands.
